# E-Commerce Business Analytics

## Project Overview

This project analyses an e-commerce company's revenue, customers, products, sellers, deliveries, payments and customer reviews.

The goal is to identify business trends, customer-retention patterns, delivery problems and opportunities to improve revenue and customer satisfaction.

## Business Objectives

- Analyse revenue and order trends.
- Identify the best-performing products and sellers.
- Measure customer repeat-purchase and retention rates.
- Segment customers using RFM analysis.
- Analyse delivery performance and delays.
- Understand the relationship between delivery delays and review scores.
- Build an interactive Power BI dashboard.
- Provide actionable business recommendations.

## Tools and Technologies

- Python
- Pandas and NumPy
- PostgreSQL
- SQL
- Power BI
- Git and GitHub
- VS Code

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

Dataset source:  
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains approximately 100,000 orders with information about customers, products, sellers, payments, reviews and deliveries.

## Project Structure

- `data/raw` – original datasets
- `data/processed` – cleaned datasets
- `src` – Python scripts
- `sql` – database and analysis queries
- `powerbi` – Power BI dashboard
- `requirements.txt` – required Python packages
